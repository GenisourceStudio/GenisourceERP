# 设计系统

与 Genisource MES 共用一套品牌语言：**暖纸色底 + 墨黑字 + 国际橙点缀**，硬边、细线、等宽字体标注。ERP 在此之上补充了「数据密集」场景所需的表格与数字规则。

## 原则

1. **信息优先，装饰让步。** 界面是给计划员和会计一天看八小时的工具，不是落地页。留白服务于扫读，不服务于美观。
2. **数字必须等宽对齐。** 金额、数量、日期统一 `font-variant-numeric: tabular-nums`，否则列无法纵向比较。
3. **状态用标签，不用颜色猜。** 单据状态一律走 `.badge`，颜色只是辅助，文字必须自解释。
4. **未开放就明确说未开放。** 占位页标注里程碑编号，不显示空表格假装功能存在。
5. **不为一个页面发明新色。** 所有颜色来自下表 token。

## Token

定义在 `frontend/src/styles/global.css` 的 `:root`。

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#ece8df` | 页面底色 |
| `--paper-2` | `#f6f3ec` | 面板、卡片、输入框 |
| `--paper-3` | `#e4dfd4` | 悬停态、次级填充 |
| `--ink` | `#101214` | 主文字、主按钮底色、侧栏选中 |
| `--ink-2` | `#191c1e` | 主按钮悬停 |
| `--muted` | `#6d6a61` | 说明文字 |
| `--muted-2` | `#7d786c` | 标签、占位符 |
| `--line` | `rgba(16,18,20,.13)` | 分隔线 |
| `--line-strong` | `rgba(16,18,20,.26)` | 面板边框 |
| `--orange` | `#ff4b12` | 焦点环、强调 |
| `--orange-text` | `#bd3a07` | 橙色文字（对比度达标的变体） |
| `--green` / `--amber` / `--red` | `#1d6b4e` / `#a86a12` / `#a8231b` | 成功 / 警告 / 危险 |

**注意**：`--orange` 直接用作文字时对纸色底对比不足，正文一律用 `--orange-text`。

## 字体

| 用途 | 字体 | 大小 |
|---|---|---|
| 正文 | Archivo Variable + PingFang SC 回退 | 14px / 1.5 |
| 等宽（数字、编码、标签） | DM Mono | 10–13px |
| 页面标题 | Archivo 650 | 15px（顶栏）/ 22px（登录） |
| 统计数值 | Archivo 650 | 26px |

等宽字体只用于：单号、物料编码、数量、金额、标签（大写 + 字距 0.12em）。

## 组件

| 类名 | 用途 |
|---|---|
| `.shell` / `.rail` / `.main` / `.topbar` / `.content` | 应用骨架 |
| `.panel` + `.panel__header` + `.panel__body` | 内容区块 |
| `.stat` + `.stat__label` + `.stat__value` | 指标卡 |
| `table.data` | 数据表格（表头大写小字、行悬停浅色） |
| `.btn` / `.btn--primary` / `.btn--ghost` / `.btn--sm` | 按钮 |
| `.badge` / `.badge--ok` / `.badge--warn` / `.badge--accent` | 状态标签 |
| `.field` + `.input` + `.form-error` | 表单 |
| `.empty` | 空状态 / 占位页 |
| `.login` 系列 | 登录页（左品牌右表单） |

## 无障碍

- 所有焦点元素有 `:focus-visible` 虚线橙色轮廓，不依赖 `outline: none`
- 表单控件用 `<label for>` 关联，占位符不承担标签职责
- 错误提示容器带 `role="alert"`
- 色彩不作为唯一信息载体（状态标签有文字）

## 响应式断点

| 断点 | 行为 |
|---|---|
| > 1180px | 4 列统计卡 |
| ≤ 1180px | 统计卡降到 2 列 |
| ≤ 900px | 侧栏转为顶部横向导航；登录页隐藏品牌区；网格转单列 |
